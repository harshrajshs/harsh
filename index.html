BACHELOR TERM PROJECT · IIT GUWAHATI

Reinforcement Learning for Task Allocation in a Mobile Edge Computing System

Studied local computation vs. MEC offloading where delays are stochastic. The work investigates Q-Learning, Double Q-Learning and MaxMin Q-Learning, then proposes QLBE to exploit useful estimation bias.

Goal: minimize expected delay costs across states/actions while controlling or exploiting estimation bias.

QLBE: use estimated variance as a signal to decide when to exploit Q-Learning overestimation or Double Q-Learning underestimation.
  • MaxMin Q-Learning reduces bias by distributing estimation across multiple Q-tables.
  • Observed instability around 1–2 Q-tables, improved stability around 3–4, with later instability associated with underestimation.
  • Derived an intermediate Random Switch Q-Learning algorithm that switches between Q-Learning with probability p and Double Q-Learning with probability 1−p.
  • Compared QLBE with Weighted Double Q-Learning: continuous weights [0,1] versus binary weights {0,1}.
  • Future work includes convergence proofs, alternative weighting mechanisms and real-time IoT/edge deployment.
Q-Learning · Double Q-Learning · MaxMin Q-Learning · QLBE · Mobile Edge Computing
MULTIMODAL INFORMATION RETRIEVAL

Apple 10-Q RAG — Engineering Notes

The RAG project treats text, tables and figures as separate modalities. It reconstructs financial tables into metric / period / value mappings, then combines lexical and semantic retrieval before cross-encoder reranking.

BM25 → lexical candidates
Sentence Transformers + FAISS → dense candidates
Hybrid pool → Cross-Encoder → Table-aware score → Evidence diversity → Grounded generation → Citation validation
  • Table score: 85% normalized cross-encoder relevance + 15% structured table relevance.
  • Final benchmark: Recall@1 60%, Recall@5 100%, Recall@8 100%, MRR 0.7750.
  • Answer, citation and abstention accuracy: 100% on the 10-question evaluation suite.
  • Production improvements identified: OCR fallback, cell coordinates, vision-language retrieval, persistent indexes, caching, CI/CD evaluation gates, authentication, tracing and observability.
PyMuPDF · pdfplumber · BM25 · FAISS · Sentence Transformers · Cross-Encoder · OpenAI · FastAPI · Docker
